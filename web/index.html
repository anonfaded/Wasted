Setup guide
  1. Create a free Supabase project at supabase.com/dashboard.
  2. In the Wasted app, open Remote Management → Open setup wizard. Paste the project URL and publishable key from the Supabase Connect dialog or Settings → API Keys. Never use the secret/service-role key.
  3. In Supabase, open the SQL Editor and run the setup SQL copied from the wizard (one paste). Then in Authentication → Providers: enable “Allow anonymous sign-ins” and turn Confirm email OFF. Then open Authentication → Hooks, choose Before User Created, and select public.hook_single_owner_signup.
  4. In the wizard, save the deployable ZIP. In Netlify, create a project with Add new project → Deploy manually and upload the ZIP. For later updates, use that same project → project menu → Deploys and upload the new ZIP in the deploy drop zone.
  5. Open your new dashboard URL and create the owner account before sharing the URL; this project allows one owner.
  6. In the app, paste the hosted URL into Remote Management, Save, and Enable. Create an enrollment token on the Devices tab and claim it in the app.
  7. Send Reset Timer here and confirm the device card updates.

Owner signup: signup is direct and no email is sent. The first account becomes the owner. The Before User Created hook blocks every later email/password signup; anonymous device identities remain allowed. Keep the dashboard URL private until the owner account exists.

Changing your account: use the Account section to change the display name. Password reset or account recovery is handled by the Supabase project owner from the Supabase dashboard, because this setup deliberately does not depend on email delivery.

Account name: saved to your Supabase account. Sign in on another browser and the same name appears under Account. You can change it there later.

The dashboard file contains only your project URL and publishable key — these are public by design, so sharing the file does not leak secrets. Anyone who can open the hosted dashboard can attempt to create an account, though your data stays protected by the database rules. Keep the URL private if you do not want that. Never share your Supabase password or a secret key.

Updating: replace index.html in the same Netlify site. Creating a new site changes the URL and requires updating Remote Management.

New device

Enroll a device

Create a single-use token, then enter it in the app: Remote Management → Enrollment token → Claim. The token is entered in the app, not on this page; each token pairs one device.

  • Valid for 10 minutes and usable once.
  • Each device needs its own token.
  • Tokens are independent; you can create several while setting up devices.
  • The token links the device's private identity to this account; your email/password is never stored on the device.
  • The app must use the same project URL and publishable key configured on this page.
  • Anyone with the token can enroll a device to this account — share it only with your own device.

Open the Wasted app → Remote Management → 4. Enroll this device, paste this token, and tap Claim enrollment. The token is not entered on this page.

Copied tokens remain in the operating-system clipboard/history. Overwrite the clipboard after enrollment.

How this works

This page was generated by the Wasted app and hosted by you. It connects directly from your browser to your own Supabase project: sign-in, data, and commands all live there. There is no dashboard server, and no wipe can be executed from the browser.

Your email/password is only for this dashboard. Devices do not receive it. Instead, the app creates a private, unnamed identity for each device, and the one-time enrollment token links that identity to your account. That is why device enrollment asks for a token, not an email.

Anonymous sign-ins are how those device identities are created. They can be left off if you do not want Remote Management; your owner account still works, but devices cannot enroll or sync. Rate limits and automatic cleanup of unused identities limit abuse.

  1. In Supabase, run the setup SQL, enable anonymous sign-ins, turn Confirm email off, and enable the Before User Created single-owner hook.
  2. Create the first account on this page; it becomes the owner immediately.
  3. In the app, paste this page's URL under Remote Management, Save, and Enable.
  4. Create an enrollment token on the Devices tab, then claim it in the app.
  5. The device appears after its first sync.

The publishable key is public by design. Never paste a secret or service-role key here.

What each device field means
Connection
Recently connected means the device contacted the server within the last 150 seconds. Otherwise the exact last-contact time is shown and commands stay queued until it reconnects.
Timer
The lock timer. While running, the remaining time between heartbeats is estimated locally from the last reported sample.
Lock timer
“actual” is what the device reports; “desired” is the account value and revision it applies at the next sync.
USB trigger
The same actual-versus-desired comparison for the USB data-connection trigger.
Debug Mode
ON blocks destructive remote commands (Force Reset). Reset Timer and settings sync keep working. Enable/Disable sends a command to that device only.
Reset support
Whether this device can perform a factory reset through Device Admin.
Last command
The newest remote command for this device and its state (queued, executing, applied, blocked, failed, …).
Install this dashboard

On Chrome or Edge, use the browser install icon or the Install app button in the header. On iPhone/iPad, use Share → Add to Home Screen. On macOS Safari, use File → Add to Dock.

Firefox desktop does not install manifest-based web apps natively. Firefox Android adds a browser shortcut instead of a standalone app.

Safety notes

Force Reset is destructive and cannot be undone. It is blocked when Debug Mode is ON and requires typing RESET in the confirmation dialog.

Revoking a device stops remote commands but does not wipe it. Reset enrollment in the app is separate and local; it does not delete the dashboard device record until you revoke that record.
